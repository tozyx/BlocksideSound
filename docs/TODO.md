## todo音效
1. 独特雨声。
   除了每种材料一个声音，还可以区分：
- 金属屋顶：细碎、清脆，暴雨时变得密集。
- 木质屋顶：偏闷、温暖的敲击。
- 树冠：大片柔和沙沙声，偶尔出现较重的水滴。
- 水面：细小溅水，避免与金属一样都是“滴答”。
- 屋檐：零星较大的滴水，与连续雨声形成层次。
- 滴水石锥的滴水、熔岩声。
- 适配不同的雨。
- 竹林
- 尤其值得做的是雨停后的短暂余滴：雨声逐渐退去，暴露在雨中的树叶和屋檐还偶尔滴几下。这个细节能让天气变化有收尾。
2. 烟花声。
   可以围绕已有烟花效果设计不同声音：
- 小型爆裂：短促、清脆。
- 大型爆裂：更厚的低频冲击。
- 星形、苦力怕形：更集中的爆裂节奏。
- 闪烁效果：零散、持续的噼啪尾声。
- 近处和远处：近处能听清细节，远处以较闷的爆响为主。
- 烟花上升声，玩家使用烟花飞行声。
- 重点是让听觉跟着烟花的视觉变化走。染色不必影响声音，大小、形状、闪烁这些特征更容易让玩家理解。鞘翅推进用的烟花最好单独调节，避免频繁飞行时太吵。
3. 掉落物撞击地面的声音（暂定）。
   玩家扔出物品，第一次接触地面时，按“物品类别＋地面材质”播放轻微声音：
- 铁锭落石头：短促金属碰撞。
- 木棍落木板：干脆的轻敲。
- 羊毛、纸张：很轻的扑落。
- 物品落水：小水花。
- 要限制频率，尤其是刷怪塔、自动农场附近；已经静止的物品也不应不断发声。
4. 船的速度与水面接触声。
   起步时有划水声，速度提高后出现船头水花，转弯时水声偏向一侧，靠岸碰撞再根据岸边材料变化。木船、竹筏还可以有不同的轻微结构声。
水下音效，体现水下的沉闷感，看可不可以加音效滤镜。

5. 特定互动的机械质感。
   挑几种玩家经常使用的物体做精细增强，例如木门合页轻响、活板门撞框、铁链受力、拉弓时弓臂和弦的张力声。建议每个动作只加一两层，保留原版清晰的反馈，避免每次开门都变成长音效。
    火把燃烧木头声。

6. 从水中上岸后的短暂滴水。
   玩家或生物离开水面后，几秒内出现逐渐减少的滴水，落在木头、石头、水面上分别有不同音色。可以和材质雨声共用一套素材与规则。
